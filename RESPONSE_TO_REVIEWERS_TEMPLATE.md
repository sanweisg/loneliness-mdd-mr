# Response to Reviewers 回复模板

## 封面信模板

```
[Date]

Dear Editor,

We are pleased to submit our revised manuscript entitled "[Title]" 
(Manuscript ID: [xxx]) for consideration for publication in Nature 
Medicine.

We thank you and the reviewers for the thoughtful and constructive 
feedback on our manuscript. We have carefully considered all comments 
and have made substantial revisions to address each point raised. 

Below we provide a detailed point-by-point response to all comments. 
All changes to the manuscript are highlighted in [red/blue] in the 
revised manuscript.

We believe these revisions have significantly strengthened the paper 
and addressed all concerns raised by the reviewers. We look forward 
to your decision.

Sincerely,
[Corresponding Author Name]
[Affiliation]
[Email]
```

## 常见问题回复策略

### 样本量问题
```
We thank the reviewer for this concern. While the sample size appears 
modest, our two-sample MR design leverages summary statistics from 
large-scale GWAS (N_exposure = XXX,XXX; N_outcome = XXX,XXX), which 
provides adequate statistical power. We have clarified this in the 
Methods section (page X, lines Y-Z) and included a formal power 
calculation in Supplementary Table X.
```

### 多效性问题
```
We appreciate the reviewer's concern about horizontal pleiotropy. 
We have conducted comprehensive sensitivity analyses including:
- MR-Egger intercept test (p = X.XX, indicating no significant 
  directional pleiotropy)
- MR-PRESSO outlier detection (removed X outliers)
- Weighted median and weighted mode estimators
- Leave-one-out analysis

These analyses are now reported in the Results (page X) and 
Supplementary Figure X.
```

### 因果方向问题
```
The reviewer correctly raises the question of causal direction. We 
have performed Steiger directionality tests, which showed that [XX]% 
of SNPs supported the hypothesized direction (Loneliness → Insomnia 
→ MDD) versus the reverse direction ([XX]%). This analysis is now 
included in Figure X and the Results section.
```

### 局限性讨论
```
We agree with the reviewer that [limitation] should be discussed. We 
have added a paragraph in the Discussion section addressing this 
limitation and its potential impact on interpretation (page X, lines 
Y-Z). We also note that this is a common limitation of MR studies 
and cite relevant guidance (reference X).
```

## 注意事项

### ✓ 必须做到
1. 逐条回复，不要遗漏
2. 引用原文评论
3. 说明修改位置（页码/行号）
4. 对所有评论表示感谢
5. 提供证据支持不同意见
6. 保持专业和尊重的语气

### ✗ 绝对避免
1. 忽略不喜欢的评论
2. 与审稿人争论
3. 声称审稿人"没看懂"
4. 攻击性或防御性语气
5. 模糊或回避性回答
6. 不承认局限性

### 重要提示
- 如果某个评论确实不合理，礼貌解释并提供证据
- 如果无法完成某项分析，诚实地说明原因
- 所有修改应在手稿中用不同颜色高亮
- 提供详细的修改说明，方便编辑和审稿人查阅
